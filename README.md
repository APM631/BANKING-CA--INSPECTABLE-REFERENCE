# BANKING-CA--INSPECTABLE-REFERENCE
Simulated banking chat agent where the user inspects the system's reasoning and directs recovery

## Project status
- **Made:** a design and simulation of a banking chat assistant. It shows its reading of a request and why, and the person can confirm, correct or reach a human.
- **Works / simulated:** storyboards, system path diagrams and a written simulation of two tests (Lab 2 and Lab 3). Everything is simulated: intent detection, account lookup, ticketing and handover are mocked.
- **Unfinished:** no runnable prototype yet, no user testing, and the data-unavailable fallback is untested. A prototype is planned for the demonstration.

## Technology stack
- Markdown (specification and simulation), Excalidraw (storyboards and Lab 2 flow chart, Lab 3 diagrams).
- No AI model runs inside the system yet. 

## Running or inspecting the work
No setup needed. Open the files in 'lab 2' and `lab3_pack`: start with `ass.01_2845031`, which is the literature review. Then the PNG diagrams. The project report is `ass.02_2845031`.

## Development record
- **Lab 1 / Assignment 1:** problem and literature review (gap: no system lets the user inspect reasoning and choose recovery).
- **Lab 2:** five-part interaction loop and three storyboards (normal, failure and recovery, secondary user). Revised the CA reading to one sentence after the secondary-user check.
- **Lab 3:** simulated a standard and a problem request, found the CA ignored account data, added a validation step and a clearer message, then reran the test.
